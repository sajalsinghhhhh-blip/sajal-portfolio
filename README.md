# Sajal Singh Portfolio

Open `index.html` in a browser. This static site uses HTML, CSS, and JavaScript; it needs no build tools.

- `index.html`: portfolio content and layout
- `styles.css`: responsive styling, dark theme, education, and concept project artwork
- `script.js`: theme toggle, mobile menu, project filters, and scroll reveals
- `assets/`: portrait photo
- `certificates/`: linked certificate PDFs

The three projects are clearly marked sample concepts, not completed work. Google Fonts loads online; system fallbacks are included.
